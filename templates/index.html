用 iPhone 相机扫码打开本页

  1. 开始录屏
    控制中心 → 录屏，等 3 秒倒计时。
  2. 手动滚动
    打开目标 App，停顿半秒，再平稳向下滚动。速度慢一点、前后保留重叠。
  3. 停止并运行
    停止录屏，在“照片”里点分享 → “长截图”；也可以直接打开快捷指令选择录屏。
  4. 保存
    等待处理完成，长图会自动存入“最近项目”，随后弹出快速查看。
手动新建备用方法（点开）

如果一键导入失败，按下面 4 个动作手动创建，效果完全一样：

  1. “选择照片”：筛选 视频，只选 1 个。
  2. “获取 URL 内容”：URL 填上面的地址；方法 POST；请求体 表单；字段 file 选“照片”。
  3. “存储到照片相簿”：输入“URL 内容”，相簿保持“最近项目”。
  4. “快速查看”：输入“URL 内容”（可选，用来先预览）。

录屏建议 3–40 秒，最长 120 秒；最多约 25 屏内容。不要在中途切到别的 App。固定状态栏、导航栏和底部 Tab 会自动裁掉，只保留一次。

边界

  • 不能自动替你滑动，仍由你手动滚动。
  • DRM/安全视频画面可能录成黑屏，这是 iOS 限制。
  • 滚动太快、完全无重叠时无法恢复缺失内容，会提示重试。
  • 聊天软件的气泡动画、悬浮按钮可能留下轻微残影。
